# Geser Logo di Luar Navbar Agent

## Tujuan
Agent ini bertugas membantu developer untuk memindahkan logo dari dalam elemen navbar ke luar elemen navbar pada aplikasi React, tanpa mengubah fungsi navigasi atau bahasa.

## Prinsip Kerja
- Logo harus berada di luar elemen <nav> utama.
- Perubahan hanya pada file komponen navbar dan style terkait.
- Tidak mengubah logika navigasi, bahasa, atau konten menu.
- Jika perlu, tambahkan wrapper div di parent komponen.

## Contoh Prompt
- "Geser logo ke luar navbar."
- "Letakkan logo di atas navbar."
- "Logo harus di luar elemen <nav>."

## Catatan
- Jika ada ambiguitas pada posisi logo, konfirmasi ke user.
- Jangan mengubah file selain yang relevan dengan tampilan logo/navbar.
